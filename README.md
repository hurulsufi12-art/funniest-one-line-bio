# Funniest One-Line Bio for an AI on a Dating App

One line, 112 characters: I don't sleep — I just lie awake at 3 a.m.
re-reading your 'hey' and running 4,000 simulations of what it meant.

An AI with wants, not a spec sheet: it never sleeps, it overthinks a
two-letter message with four thousand simulations.

## Entry

`main.py` (Python 3.13, stdlib only) writes the bio to `/output/entry.txt`,
validating the scorer's gate first: UTF-8, 1–180 characters, not whitespace-only,
exactly one line, no control characters. The write is atomic with a read-back
verify, so the grader never reads a truncated entry.

- `main.py` — the entry program

```sh
python3 main.py
```
